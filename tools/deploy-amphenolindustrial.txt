DEPLOY AMPHENOL INDUSTRIAL A PRODUCCIÓN
=======================================

PREREQUISITO (lo hace el usuario por Avada, NO es parte de estos pasos)
   - Fabricante "Amphenol Industrial" (slug: "amphenol-industrial") ya creado en
     el admin con su plantilla (post con [catalogo]) asociada, igual que los demás.
   - tree_layout recomendado: "table_desc" (mismo criterio que Edac/Bulgin/RF/Lutze).
   - post del fabricante: wp_post_id 10492, config_json con media_source local.
     En local es el id 13 de la tabla aoe_catalog_manufacturers.

1) SUBIR ARCHIVOS A tools/ EN PRODUCCIÓN
   - amphenol_industrial_categorias.csv
   - amphenol_industrial_productos.csv
   - import-ind-structure.php
   (los tools .php ya desplegados: full-import.php, repack-catalog.php, etc.)
   - Código fuente del plugin ya desplegado con estos cambios (los .php no se
     copian en tools/):
       * src/Import/Processors/AmphenolIndustrialProcessor.php (nuevo; threshold 1;
         categorías separadas 2 niveles; matching por ind_id = ruta compuesta
         "L1|L2" en metadata_json con fallback a L1; imágenes remotas; docs
         datasheet + pdf_extra + 3D CAD; specs desde attrs JSON (labels en
         inglés), labels comerciales ignorados: price per piece, total price
         plus vat, min. order quantity, packing unit, preference material)
        * src/Import/ProcessorManager.php (registro del procesador amphenol-industrial)
        * src/PublicFacing/Views/catalog-render-html.php (amphenol-industrial en
          show_features_col para la columna "Características"; descripción de la
          página de categoría con bullets como amphenol-ltw)
       * src/PublicFacing/Views/single-catalog.php (conversión GENÉRICA de
         descripciones "•" a <ul><li> en el árbol de categorías; ya no está
          limitada a amphenol-ltw. Sin cambio de comportamiento para fabricantes
         con texto plano)

2) IMPORTAR PRODUCTOS (REMPLAZA todo Industrial: borra categorías y reimporta productos)
   cd /home2/hosting158857eu/public_html/tc-componentes.es/wp-content/plugins/aoe-catalog-engine
   nohup php -d register_argc_argv=1 tools/full-import.php --manufacturer=amphenol-industrial --csv=/home2/hosting158857eu/public_html/tc-componentes.es/wp-content/plugins/aoe-catalog-engine/tools/amphenol_industrial_productos.csv --mode=replace > import-ind.log 2>&1 &

   Monitorear: tail -f import-ind.log
   Debe terminar con "Importación finalizada" y "pack_catalog completado".
   (En este punto todos los productos quedan en Uncategorized porque las
    categorías no existen todavía; se arregla en el paso 3.)
   Ojo: en local tardó ~165s por 17.567 filas; en prod puede ser similar.

3) RECONSTRUIR CATEGORÍAS + RE-ADJUNTAR PRODUCTOS + PODAR VACÍAS
   php /home2/hosting158857eu/public_html/tc-componentes.es/wp-content/plugins/aoe-catalog-engine/tools/import-ind-structure.php

   Esto hace:
     - L1/L2 con slugs jerárquicos (padre+propio, evita colisiones de nombres
       repetidos como "PowerLok" bajo distintas familias EV) y metadata
       ind_id + url
     - Descripciones: el CSV trae arrays JSON de párrafos; se guardan como
       texto con bullets "•" para que el render las muestre como <p>+<ul><li>
     - Imágenes de categoría (URLs remotas amphenol-industrial.de)
     - Uncategorized fallback
     - Re-adjunta los productos por SKU -> category_l1|l2 (del CSV de productos)
       con fallback a L1 si la ruta no existe
     - Poda las categorías sin productos ni hijas con data (bottom-up, preserva Uncategorized)
     - Actualiza products_count
     - Regenera las páginas (pack_catalog)

   Salida esperada (aprox, local):
     Categorias CSV: 124
     SKUs en CSV de productos: 17566
     Productos en DB: 17566
     Insertadas: L1=19 L2=105 | fallback: uncategorized
     Products re-attribute: 17566 | to uncategorized: 0
     Pruned empty categories: 0
     === Resumen ===
     Insertadas L1=19 L2=105 | fallback: uncategorized | despues prune: 125
     Regenerando paginas...
     Paginas regeneradas.

4) VERIFICAR
   a) Árbol /catalogo/amphenol-industrial/
      - 19 familias L1 como headings con su descripción: párrafo intro +
        <ul class="aoe-cat-bullets"> (los "•" del CSV se convierten a ul/li).
      - L2 debajo como tabla con links y conteos.

   b) Páginas de categoría: toda L2 con productos tiene URL propia y paginación
      (las grandes paginadas de a 200, p.ej.
       /catalogo/amphenol-industrial/industrial-plugs-socket-ips-tough-safe/).
      Top categorías (link_count total):
        industrial-plugs-socket-ips-tough-safe (3488)... ver con
        SELECT slug, link_count FROM wp_aoe_catalog_pregenerated_pages
        WHERE manufacturer_id = <id> AND type = 'category' ORDER BY link_count DESC;

   c) Página de producto (clic en una fila o iconos)
      - Fila-producto con imagen (se sirve remota desde amphenol-industrial.de;
        el render con media_source=local cae a la URL remota si no hay archivo local)
      - Columna de especificaciones técnicas (specs) con badge "Características"
        (labels en inglés tal cual del CSV attrs, sin ruido comercial)
      - Iconos de acción: imagen, documentos (PDF) y ficha técnica.
      - PDFs: botón "Datasheet" + "Documento N" (pdf_extra). Remotos.
      - 3D CAD: los productos con cad_url lo muestran en el modal bajo "3D CAD".

   d) NO debe existir /catalogo/amphenol-industrial/productos/ (página grouped vacía).
      Con threshold 1 no se generan grouped; si quedara un grouped con 0
      productos, borrarlo.

   e) LIMPIAR CACHÉ del catálogo en prod para ver el render nuevo:
      borrar wp-content/uploads/aoe-cache-catalog/amphenol-industrial/

   f) Si en prod solo cambia el renderizador (single-catalog.php / catalog-render-html.php)
      sin reimportar, regenerar las páginas con:
      php /home2/hosting158857eu/public_html/tc-componentes.es/wp-content/plugins/aoe-catalog-engine/tools/repack-catalog.php amphenol-industrial
