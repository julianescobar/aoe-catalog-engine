DEPLOY AMPHENOL ANYTEK A PRODUCCIÓN
====================================

PREREQUISITO (lo hace el usuario por Avada, NO es parte de estos pasos)
   - Fabricante "Amphenol Anytek" (slug: "amphenolanytek") ya creado en el admin
     con su plantilla (post con [catalogo]) asociada, igual que los demás.
   - tree_layout recomendado: "table_desc" (para que el árbol salga como Edac/Bulgin).
   - post del fabricante: wp_post_id 10492.

1) SUBIR ARCHIVOS A tools/ EN PRODUCCIÓN
   - categoriassamphenoanytek.csv
   - productosamphenoanytek.csv
   (los tools .php del plugin ya deben estar desplegados:
    full-import.php, import-anytek-structure.php, pack-catalog.php, etc.)
   - Código fuente del plugin ya desplegado con estos cambios (los .php no se
     copian en tools/):
       * src/Import/Processors/AmphenolAnytekProcessor.php (get_page_threshold() = 1,
         así toda categoría con productos tiene URL propia; no cae al grouped)
       * src/Import/ProcessorManager.php (registro del procesador amphenolanytek)
       * src/PublicFacing/Views/catalog-render-html.php (amphenolanytek en show_features_col)
       * src/PublicFacing/Views/single-catalog.php (regla de tablas generalizada:
         un nivel cuyos hijos sean todos hojas con productos renderiza como tabla;
         antes esto solo aplicaba a bulgin)

2) IMPORTAR PRODUCTOS (REMPLAZA todo Anytek: borra categorías y reimporta productos)
   cd /RUTA_DEL_SITIO/wp-content/plugins/aoe-catalog-engine
   nohup php tools/full-import.php --manufacturer=amphenolanytek --csv=tools/productosamphenoanytek.csv --mode=replace > import-anytek.log 2>&1 &

   Monitorear: tail -f import-anytek.log
   Debe terminar con "Importación finalizada" y "pack_catalog completado".
   (En este punto todos los productos quedan en Uncategorized porque las
    categorías no existen todavía; se arregla en el paso 3.)

3) RECONSTRUIR CATEGORÍAS + RE-ADJUNTAR PRODUCTOS + PODAR VACÍAS
   php tools/import-anytek-structure.php

   Esto hace:
     - L1 familias / L2 subcategorías / L3 con metadata anytek_id + url
       (del CSV de categorías; salta las filas "series" numéricas que chocan)
     - Uncategorized fallback
     - Re-adjunta los productos por SKU -> list_cate_id (del CSV de productos;
       IDs de categoría son ANYTEK IDs, no numéricos)
     - Poda las categorías sin productos ni hijas con data (bottom-up, preserva Uncategorized)
     - Actualiza products_count
     - Regenera las páginas (pack_catalog)

   Salida esperada (aprox, local):
     Categorias CSV (tras filtrar series numericas): 42
     SKUs en CSV de productos: ~19478
     Productos en DB: ~18890
     Insertadas: L1=8 L2=20 L3=14 | fallback: uncategorized
     Products re-attribute: ~18890 | to uncategorized: 0
     Pruned empty categories: ~9
     === Resumen ===
     Insertadas L1=8 L2=20 L3=14 | fallback: uncategorized | despues prune: 33
     Regenerando paginas...
     Paginas regeneradas.

4) VERIFICAR
   a) Árbol /catalogo/amphenolanytek/
      - Las ramas cuyos hijos son todos hojas con productos salen como TABLA
        (ej. "IC/SKT System" con sus tipos debajo), no como headings.
      - Los conteos (n) en los headings y links a cada categoría.
      - Descripciones de las L1 en párrafos.

   b) Páginas de categoría: toda categoría con productos tiene URL propia
      (ej. /catalogo/amphenolanytek/ic-skt-system/,
      /catalogo/amphenolanytek/commercial-relay/).
      Las grandes quedan paginadas:
      /catalogo/amphenolanytek/rising-clamp-system-type-2/, ... -13
      /catalogo/amphenolanytek/spring-clamp-system-type-2/, ... -14

   c) Página de producto
      - Fila-producto con imagen
      - Columna de especificaciones técnicas (specs) con badge "Características"
      - PDFs con los labels descargables

   d) NO debe existir /catalogo/amphenolanytek/productos/ (página grouped vacía).
      Con threshold 1 no se generan grouped (todas las categorías con productos
      son "large"); si quedara un grouped con 0 productos, borrarlo.

   e) LIMPIAR CACHÉ del catálogo en prod para ver el render nuevo:
      borrar wp-content/uploads/aoe-cache-catalog/amphenolanytek/

NOTAS
   - El orden importa: full-import --mode=replace BORRA todas las categorías Anytek,
     por eso el paso 3 reconstruye las categorías después.
   - 18890 productos en DB; 18887 con imagen, 18890 con PDF y specs.
   - 33 categorías finales: 7 L1, 13 L2, 13 L3, todas con productos o descendencia
     (Uncategorized se preserva aunque quede vacío).
   - Páginas generadas: 1 tree + 111 category.
   - AOE_DB_HOST=127.0.0.1:10006 es solo para local (bypass del socket de Local).
